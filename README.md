# 媒体图床管家

SillyTavern 使用者版媒体图床管理扩展。

当前版本：v0.25.0。使用旧仓库最后一版 author 功能作为底稿，仅保留使用者需要的功能。

## 功能

- 按角色卡、世界书和美化分类手动扫描媒体链接。
- 定位失效图片及音频，并批量替换。
- 角色卡扫描包含开场白、正则、小手机、内嵌世界书和绑定世界书。
- 支持手动备份、修改记录和恢复。
- 自动获取作者发布的喵呜图床修复，并询问是否一键同步。
- 提供“喵呜帮你修复”手动按钮，错过启动提示后可以再次检查。
- 自动检查角色卡本体、内嵌内容、小手机和绑定世界书中的旧链接。
- 主动替换作者版残留界面，避免同时安装旧作者版时显示发布按钮。

本仓库为使用者版本，不包含作者发布修复入口。

## 安装

在 SillyTavern 的“安装扩展”中填写：

`https://github.com/DDDayDreamwhite/image-source-plugin`
