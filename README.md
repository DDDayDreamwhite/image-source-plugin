# 媒体图床管家

SillyTavern 使用者版媒体图床管理扩展。

当前版本：v0.29.0。使用旧仓库最后一版 author 功能作为底稿，仅保留使用者需要的功能。

## 功能

- 按角色卡、世界书和美化分类手动扫描媒体链接。
- 定位失效图片及音频，并批量替换。
- 角色卡扫描包含开场白、正则、小手机、内嵌世界书和绑定世界书。
- 会遍历角色内嵌世界书和绑定世界书的所有条目；任何条目只写 `4z9k83.png` 这类图片文件名时，都会尝试读取对应角色正则正在使用的图床前缀，拼成完整链接后检查是否失效。
- 支持定位到“日常立绘 / 特殊立绘 / NSFW立绘 / 背景”等具体分区，并对同类失效图片一键替换。
- 换成其他图床的完整链接时，会同步把对应正则改成兼容完整链接的写法，避免继续强加旧 Catbox 前缀。
- 同一图片同时存在纯文件名和完整链接时，会按完整内容优先替换，避免两种写法互相干扰。
- 支持识别正则中 `https:\/\/...` 形式的转义图片地址；单独扫描世界书时也会读取对应的角色正则用于匹配。
- 支持手动备份、修改记录和恢复。
- 自动获取作者发布的喵呜图床修复，并询问是否一键同步。
- 提供“喵呜帮你修复”手动按钮，错过启动提示后可以再次检查。
- 喵呜修复可按人物姓名识别不同卡片版本里的当前旧头像链接，并全局替换所有相同引用。
- 喵呜修复按可信清单中的卡名匹配，不再因导入后创作者元数据变化而漏掉修复。
- 已迁移旧作者仓库工单中的 ECLIPSE 与梁曜文完整修复明细。
- 自动检查角色卡本体、内嵌内容、小手机和绑定世界书中的旧链接。
- 主动替换作者版残留界面，避免同时安装旧作者版时显示发布按钮。

本仓库为使用者版本，不包含作者发布修复入口。

## 安装

在 SillyTavern 的“安装扩展”中填写：

`https://github.com/DDDayDreamwhite/image-source-plugin`
